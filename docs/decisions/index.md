# Design Decisions {#decisions}

Decision records explain why a design was chosen. They should be short,
dated when possible, and link back to the conceptual docs they affect. ADR
numbers follow documentation order, not necessarily original project history.

- @subpage decision_0001_adopt_architecture_decision_records "0001: Adopt Architecture Decision Records"
- @subpage decision_0002_mm_reserve_commit_map "0002: MM Reserve, Commit, and Map"

Older design choices can be added later as retrospective ADRs when documenting
them clarifies current code. Do not block new records on reconstructing the
entire project history.
