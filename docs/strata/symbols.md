# Symbols {#strata_symbols}

This page describes kernel symbol metadata, static lookup, panic-time lookup,
and future runtime symbol loading.

## Static Symbol Information

Strata links a compact static symbol table into the kernel image. The table is
generated by host tools and exposed to the kernel through weak symbol anchors.
`StSymbol_LookupStatic` performs address lookup against that table and returns:

- original address;
- symbol base address;
- offset from the symbol;
- symbol name;
- object name;
- optional file/line fields;
- flags.

The object name for the built-in table is currently `strata`.

## Formatting

`StSymbol_FormatStatic` formats an address into a fixed caller-provided buffer.
If no symbol is found, it falls back to an address-style representation. The
panic path uses the static formatter because it is simple enough for early,
interrupt, and panic contexts.

## Generic Entry Points

`StSymbol_Lookup` and `StSymbol_Format` are the generic names. They currently
delegate to the static implementation, but they leave room for later runtime
symbol sources such as loaded modules or disk-backed ELF parsing.

Do not make panic-time stack traces depend on filesystem access or heap-heavy
ELF parsing. Richer symbol resolution can be added for normal runtime contexts
without weakening the static panic path.
